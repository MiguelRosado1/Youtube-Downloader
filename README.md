# Youtube-Downloader
Since i couldn´t find any good youtube download apps, i said to myself, "What if i make one?" and it was surprisingly eazy.

## dependencies
- yt-dlp

# How to use?
1. Copy the url of the youtube video
2. select the format you want either mp3 or mp4
3. paste it
4. wait a few seconds
5. and there you have it and .mp3/mp4 file
